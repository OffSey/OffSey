## 🧑‍💻 About Me

I'm a developer focused on the **FiveM ecosystem**, building tools and platforms designed to improve server quality, performance, and player experience.

- 🛡️ **Owner & Developer of [XionShield](https://xionshield.eu)** — real-time cheat detection and instant bans for FiveM servers.
- 🎁 **Owner of [XionGift](https://xiongift.eu)** — a giveaway platform where players earn points and win FiveM scripts, resources and hosting.
- 🧊 **Owner of [Cube Scripts](https://cubescripts.com)** — premium FiveM scripts, optimized, secure and fully supported.
- 💼 **Developer** for shops and servers in FiveM.
